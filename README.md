A structured 30-day journey covering core Android development concepts from scratch — UI components, layouts, database, API integration, navigation, and more — all built with **Kotlin** in **Android Studio**.

## ⚙️ Getting Started

### Prerequisites
- Android Studio (Hedgehog or later)
- Android SDK (API 21+)
- Kotlin plugin enabled

### Run Any Project

```bash
# 1. Clone the repository
git clone https://github.com/yaahrit/30DaysOfAppDev-Course.git

# 2. Open Android Studio
# File → Open → Select any Day folder (e.g., Day24RecyclerView)

# 3. Let Gradle sync complete

# 4. Run on emulator or physical device
# Click ▶ Run button
```
